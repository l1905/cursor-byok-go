# 2026-11-18 Cursor 3.31 兼容修复

- 版本：v1.0.2（基于 leookun/cursor-byok v1.0.1）
- 验证环境：macOS arm64，Cursor 3.31.3

## 问题

升级到 Cursor 3.31.3 后，开启 cursor-byok 时所有对话失败，**官方模型和 BYOK 自定义模型都不能用**。Cursor 报错：

```
The server failed 4 times. Please try again, or contact support if the issue persists.
```

代理、证书、模型列表都正常。失败只发生在发消息时：Cursor 日志里每次 `BidiAppend` 都返回 `InvalidArgument`。

## 原因

Cursor 3.31 同时改了两处：

| # | 变化 | cursor-byok 旧行为 | Cursor 日志中的报错 |
|---|------|-------------------|-----------|
| 1 | `BidiAppendRequest` 消息内容从 `data`（hex 字符串）改到 `data_binary`（原始字节） | 碰到 `data_binary` 直接拒绝 | `BidiAppend data_binary is not part of the captured protocol` |
| 2 | 新开关 `agent_host_local_loop` 打开后，agent 循环改由客户端执行，只通过 `aiserver.v1.InferenceService/RunInferenceSSE` 请求模型输出，`BidiAppend` 里装的是 `RunInferenceClientMessage` | 只实现了后端循环 `agent.v1.AgentService/RunSSE`，仍按 `AgentClientMessage` 解码 | `protobuf decode error ... ConversationStateStructure.summary ... invalid wire type` |

`BidiAppend` 在选择路由（BYOK / 官方）之前就要解码，所以解码一失败，官方模型也跟着不可用。

```
Cursor 3.31 ──BidiAppend──▶ cursor-byok 解码 ──✗──▶ 还没走到路由（BYOK / 官方）
```

## 改动

```
server/src/
├── api/cursor/bidi.rs                 # decode()：优先用 data_binary，为空时回退 hex data
└── cursor/services/analytics.rs       # BootstrapStatsig 开关覆盖：新增 agent_host_local_loop=false
apps/desktop/                          # 桌面端版本号 1.0.1 → 1.0.2
```

- **改动 1**：新旧两种编码都能解码。
- **改动 2**：cursor-byok 本来就会修改 Cursor 启动时拿到的开关配置（`AnalyticsService/BootstrapStatsig`）。现在把 `agent_host_local_loop` 固定为 `false`，让 Cursor 继续走 `AgentService/RunSSE` 这条 cursor-byok 已支持的路径。上游返回的配置和本地兜底配置都会改。

## 测试

- 单元测试：`bidi` 的两种编码解码结果一致、空消息被拒绝；`analytics` 在三种 Statsig hash 方式（none / djb2 / sha256）下都能把开关强制关闭。
- 手动测试：Cursor 3.31.3 中官方模型和 BYOK 模型都能正常对话。

## 已知风险与后续

- **依赖旧路径**：如果 Cursor 以后删掉 `AgentService/RunSSE` 这条后端循环，或者不再读 `agent_host_local_loop` 开关，就要完整实现 `InferenceService/RunInferenceSSE`（客户端循环下由 cursor-byok 提供模型输出）。
- **proto 提取器在 3.31 上失败**：`support/cursor-protocol-extractor` 校验时报 `agent.v1.ListAgentHostSessionsRequest` 字段 tag 重复，这次没有更新 `protocols/cursor/*.proto`。字段定义是直接从 Cursor 的 JS 产物中读取的，例如 `extensions/cursor-agent-host/dist/main.js` 里的 `static $(){return["Message|no name type..."]}`。
- **自动更新仍指向上游**：`tauri.conf.json` 的 updater endpoint 和公钥还是 leookun/cursor-byok 的。上游发布更高版本后，应用内更新会覆盖本 fork 的版本。
